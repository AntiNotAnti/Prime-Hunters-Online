per-profile hit counters, paired divergence classifications and first divergence

identity denominator and remain classified in the JSON.

## Reproduction

Use legally obtained game assets and a user-data directory containing `paths.txt`.
Build `tools/nettest` with .NET 10; invoke its DLL with each `--<suite>` named in
the JSON. Asset suites also take the user-data directory argument. Example:

```sh
dotnet build tools/nettest
dotnet run --project tools/nettest --no-build -- --protocol19
dotnet run --project tools/nettest --no-build -- --protocol19-scene "$PRIME_TEST_DATA"
dotnet run --project tools/nettest --no-build -- --network-benchmark-json benchmark.json --extended
```

Stage the game runtime with its native dependencies, then run:

```sh
python3 tools/hitrig/run-continuous.py --runtime "$PRIME_TEST_RUNTIME"   --data "$PRIME_TEST_DATA" --output /tmp/prime-v19-matrix   --players 2 --seconds 20 --profiles all --modes shockcoil
python3 tools/hitrig/compare-continuous.py /tmp/prime-v19-matrix   --output /tmp/prime-v19-pairs.json
for mode in off aggregate study; do
  python3 tools/hitrig/run-continuous.py --runtime "$PRIME_TEST_RUNTIME"     --data "$PRIME_TEST_DATA" --output "/tmp/prime-v19-$mode"     --players 8 --seconds 40 --profiles rtt320-loss2     --modes shockcoil-all --telemetry "$mode"
done
```

Replay checks use the staged executable's `-replayformatcheck` and
`-replayworldcheck 'room:MP1 SANCTORUS'` with an isolated `-output` directory and
`PROJECT_PRIME_USER_DATA` set. Headless playback does not establish rendered
visual quality. Game assets, raw traces and private runtime directories are not
included in the repository.

## Remaining release gates

- Shock Coil hit-count agreement under impairment remains below the requested
  threshold despite accepted target identity convergence.
- General counterfactual ballistic, homing, continuous, turret and dynamic-world
  outcomes are not simulated. Unsupported shadow geometry is explicitly unknown.
- No production deployment or real-player population has been collected. The
  planned thousands of matches across maps, weapons and connection buckets remain
  necessary before enforcement can be considered.
- Cross-platform GitHub CI was still running when this record was authored; local
  success is not a claim that all hosted checks passed.

Production stays in Shadow with the 45-frame ceiling and existing claim policy.
