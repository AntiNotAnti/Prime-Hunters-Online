# Project Prime combat feedback sounds

These WAV stingers are original, programmatically synthesized assets created for Project Prime.
They use no third-party recordings or samples.

Built-ins:
- headshot-prime.wav
- headshot-impact.wav
- headshot-arena.wav
- double-kill.wav
- triple-kill.wav
- overkill.wav
- killtacular.wav
- killtrocity.wav
- kilimanjaro.wav
- killtastrophe.wav
- killpocalypse.wav
- killionaire.wav
- killing-spree.wav
- killing-frenzy.wav
- running-riot.wav
- rampage.wav
- untouchable.wav
- invincible.wav

Legacy `quadra-kill.wav` and `penta-kill.wav` resources remain embedded so saved
preferences from older builds continue to resolve during migration.

Players can override any combat-feedback event with WAV, MP3, or FLAC files from the
user-data `sounds/combat` folder.
