ipcountry.bin.gz

IP-to-country ranges, built from the DB-IP Lite country database.

    <a href="https://db-ip.com">IP Geolocation by DB-IP</a>

    https://creativecommons.org/licenses/by/4.0/
    https://db-ip.com/db/download/ip-to-country-lite

Format, which is this project's and not DB-IP's: the CSV filtered to IPv4,
sorted, and packed as

    "FPGEO1"                     6 bytes
    country count                uint16, little-endian
    country codes                2 ASCII bytes each
    range count                  uint32, little-endian
    ranges                       uint32 first address + uint8 country index

Ranges are sorted and contiguous: the country of an address is the country of
the last range whose first address is at or below it, which is one binary
search and no allocation. Rebuild it with tools/build-ipcountry.py.
